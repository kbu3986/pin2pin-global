# 01. Master Plan — Pin2Pin Global

## 1. 해결하려는 시장 문제 (Pain Point)

전 세계 하드웨어 엔지니어, 펌웨어 개발자, 구매(BOM) 담당자, 전자공학 전공자는 매일 다음 3가지 문제를 구글에 검색한다.

1. **단종·납기 지연 대응** – `"XC6206P332MR alternative"`, `"TPS613221A pin to pin replacement"`, `"LM358 lower noise equivalent"`처럼 기존 PCB를 수정하지 않고 바로 교체할 수 있는 핀호환 대체품을 찾는다.
2. **스펙 1:1 비교 검증** – `"AMS1117 vs ME6211"`, `"MCP6001 vs TLV9001"`, `"AO3400 vs SI2302"`처럼 데이터시트 2개를 열어두고 대기전류($I_Q$), 드롭아웃 전압($V_{DO}$), ESR 안정성, 열저항을 비교하는 데 30분 이상 소모한다.
3. **회로 적용 실수 방지** – 핀 번호 순서(예: SOT-23-3에서 GND-IN-OUT vs IN-GND-OUT 혼동), 세라믹 커패시터 발진(ESR 조건), 최소 부하 전류 같은 함정을 빠르게 확인하고 싶어 한다.

기존 부품 검색 사이트(AllDatasheet, Octopart, DigiKey)는 **PDF 원문 링크나 단순 파라미터 필터**만 제공할 뿐, 엔지니어 관점의 **"바로 꽂아도 되는지(Drop-in), 저항값만 바꾸면 되는지(Functional), PCB 패턴을 떠야 하는지(Layout-Mod)"**에 대한 직관적 비교 판정과 회로 주의사항을 주지 않는다.

## 2. 왜 '20배 토큰 소모형' 프로젝트로 완벽한가

단순 텍스트 생성 사이트는 구글 Helpful Content / Scaled Content Abuse 업데이트에 취약하지만, `Pin2Pin Global`은 토큰의 85퍼센트를 **데이터 추출, 교차 검증, 공학적 계산, 시각 자산(SVG 핀맵) 코드 생성**에 태운다.

| 비교 항목 | 일반 AI 슬롭 블로그 | Pin2Pin Global (고토큰 해자 모델) |
| :--- | :--- | :--- |
| **입력 소스** | 프롬프트 한 줄 (모델 기억 의존) | 제조사 공식 PDF 데이터시트 원문 + 애플리케이션 노트 |
| **검증 구조** | 1회 생성 후 즉시 게시 | 추출 → 적대적 물리법칙 검증 → 핀맵 대조 → 원문 페이지 인용 확인 |
| **할루시네이션 통제** | 핀아웃·정격 오기재 빈발 | 불확실 필드 `UNVERIFIED` 격리 및 미검증 페이지 빌드 차단 |
| **고유 정보 이득** | 기존 글 재요약 (정보 이득 0) | 동적 핀맵 SVG 비교, 실동작 $T_J$ 계산기, 3등급 호환 판정표, ESR·디레이팅 경고 |
| **복제 난이도** | 5분 만에 복제 가능 | 부품 1,000종당 2억–3억 토큰 + HW 검증 룰셋 필요 |

## 3. 타깃 유저 및 시장 규모

1. **1차 타깃 (글로벌 영어권 · 최우선)** – 미국·유럽·인도·글로벌 HW 설계자, PCB 아트워크 담당자, 전자부품 소싱 매니저 (검색량 70퍼센트 이상, 최고 CPC).
2. **2차 타깃 (일본어 · 독일어)** – 산업용·전장·계측기 제조 강국으로 B2B 부품 검색 트래픽과 광고 단가가 매우 높음.
3. **3차 타깃 (한국어)** – 국내 전자개발자, 대학원생, 중소 제조사 HW 담당자 (네이버·구글 병행 유입 및 국내 커뮤니티 바이럴 거점).

## 4. 핵심 기능 구성 (MVP → Scale-up)

### A. 부품 정밀 프로파일 페이지 (`/part/[mpn]`)
- 공식 데이터시트 기반 핵심 전기적 사양 표 (모든 수치 옆에 원문 PDF 페이지·테이블 번호 출처 표시).
- 자동 생성 SVG 패키지 핀아웃 도면 (SOT-23-3, SOT-23-5, SOIC-8, QFN 등 표준 패키지 매핑).
- 엔지니어 실무 주의사항(Design Gotchas): 세라믹 커패시터 ESR 발진 주의, 열패드(EP) GND 연결 여부, 절대최대정격 마진.
- 인터랙티브 공학 계산기 위젯 (LDO 발열·접합온도 $T_J$ 계산, DC-DC 효율·인덕터 리플 근사, Op-Amp 대역폭·슬루율 체크).

### B. 1:1 부품 정밀 비교 페이지 (`/vs/[mpn-a]-vs-[mpn-b]`)
- 두 부품의 핀아웃 SVG 나란히 대조 (동일 핀 녹색, 불일치 핀 적색 하이라이트).
- 핵심 파라미터 승패 매트릭스 (대기전류, 최대전류, 노이즈/PSRR, 패키지, 예상 단가대).
- **교체 시나리오 판정 배지**:
  - `Level 1: Drop-In Compatible` (핀아웃·패키지·핵심 정격 일치, 무수정 교체 가능).
  - `Level 2: Functional / Tuning Required` (동일 기능이나 피드백 저항·출력 커패시터 재계산 필요).
  - `Level 3: PCB Layout Change Required` (핀 배열 상이 또는 패키지 변경 필요).

### C. 대체품 마스터 허브 페이지 (`/alt/[mpn]-alternatives`)
- 단종·고가·수급난 부품 기준으로 Drop-In 후보 3–5종, 저전력 특화 후보, 초저가(중국산 LCSC 주력) 후보, 고신뢰성(TI/ADI/ST/Infineon) 후보를 한눈에 비교.

### D. Phase 4 확장: BOM CSV 대체품·단종 리스크 진단기 (Micro-SaaS)
- 사용자가 KiCad/Altium/PADS에서 뽑은 BOM CSV를 올리면 10초 만에 부품별 대체품 후보와 단종(NRND/EOL) 리스크 리포트를 생성(무료 10라인, 유료 월 19달러 무제한).

## 5. 법적 리스크 및 품질 안전장치

1. **저작권 준수** – 제조사 PDF 원문 자체를 재배포(호스팅)하지 않고, 공식 제조사/유통사 PDF 링크를 연결하며 사실적 수치(Facts/Specifications)만 자체 구조화 DB와 자체 생성 SVG로 표현한다.
2. **엔지니어링 면책 조항 (Engineering Disclaimer)** – 모든 페이지 하단과 비교 표 상단에 `"최종 양산 및 의료·전장 등 안전 필수 회로 적용 전 반드시 제조사 최신 공식 데이터시트 원문을 재확인해야 함"` 고지를 의무 배치한다.
3. **데이터 신선도 타임스탬프** – 모든 부품 레코드에 `datasheet_rev`, `verified_at`, `source_url`을 명시해 신뢰도를 극대화한다.
